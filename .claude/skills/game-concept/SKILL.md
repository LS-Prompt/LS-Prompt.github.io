# 게임 콘셉트

## 1. 조건 확인
사용자에게 아직 정해지지 않은 것만 묻는다(최대 3개): 장르/분위기, 한 판 길이, 조작 방식(키보드·터치·원버튼), 참고하고 싶은 느낌.

## 2. 발산 — 후보 3개
`game-designer` 관점으로 서로 성격이 다른 후보 3개를 만든다. 각 후보:
- 가제 / 한 줄 피치 / 코어 동사(플레이어가 계속 하는 행동 1~2개)
- 30초 플레이 묘사 / 차별점 / 구현 난이도(S·M·L)

장르·메커니즘 참고는 괜찮지만 특정 기존 게임의 이름·캐릭터·아트·레벨을 재현하는 후보는 만들지 않는다.

## 3. 수렴
`creative-director` 기준(첫 30초 재미, 한 문단 규칙, 범위, 오리지널리티)으로 점수표를 만들고 추천안을 제시한다. 사용자가 고르게 한다.

## 4. 저장
선택된 안으로 슬러그(영문 소문자-하이픈)를 정하고 `studio/templates/concept.md`를 채워 `studio/games/<slug>/concept.md`에 저장한다.
마지막에 다음 단계로 `/game-design-doc`을 안내한다.
