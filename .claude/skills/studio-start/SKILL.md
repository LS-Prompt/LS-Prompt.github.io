# 스튜디오 시작

1. `studio/games/` 아래 폴더 목록을 확인한다. 비어 있으면 "새 게임을 시작하려면 `/game-concept`"를 안내하고, 장르·플레이 시간·플랫폼(PC/모바일) 선호를 물어본다.
2. 게임별로 다음 문서 존재 여부를 확인해 단계를 판정한다:
   `concept.md` → `gdd.md` → `sprint-*.md` → `public/games/<slug>/index.html` → `playtest-*.md` → `postmortem.md`
3. 가장 최근 스프린트 문서의 미완료 항목과 최근 플레이테스트의 미해결 이슈를 모은다.
4. 다음 형식으로 보고한다:

```
## 스튜디오 현황
| 게임 | 단계 | 최근 변경 | 미해결 |
## 추천 다음 작업
1. (스킬 또는 에이전트 이름) — 이유
```
코드를 수정하지 않는다.
